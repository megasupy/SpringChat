# SpringChat

A basic chat application developed with Spring Boot, HTMX, PicoCSS, and PostgreSQL

## Features
- Login/Signup with username and password.
- Users can message all other users of the site.

## Stack
- Spring Security for username/password Authentication.
- Flyway for Database Migrations.
- Thymeleaf for serving HTML templates
- HTMX for dynamic site updates
- JDBC for SQL queries
- PostreSQL for database.
